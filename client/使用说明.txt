H800 Atlas 团队工作台

Windows
1. 解压整个启动包，双击「打开工作台.cmd」。
2. 在终端输入自己的 H800 SSH 用户名。使用密码建立 SSH 连接时，按终端提示输入密码，输入时屏幕不会回显。已配置 SSH 密钥的用户可用自己的密钥建立隧道。
3. 保持终端打开，在浏览器访问 http://127.0.0.1:18769/，用自己的 H800 SSH 用户名和密码登录。
4. 使用结束时点击网页右上角「退出」，再关闭终端。

macOS / Linux
在解压目录运行 sh start.sh，按提示建立隧道，然后打开同一网址。
需要 OpenSSH，以及到 36.103.247.214 的 TCP 60011 端口的连通性。账号需要具备 H800 Shell 和 SSH 转发权限，并能读取 /workspace/gzqherry/h800-atlas-team 中的程序。

更新
工作台运行在 H800 上。维护者发布后，下次打开即为新版。已打开的可见标签页每 10 秒检查一次版本，返回后台标签页时也会检查。登录网关升级后需要重新登录。
